# RSA

![](/Misc/RSA/1.png)

为什么公钥可以随便给，私钥自己留，不怕破解，全在一组数字的构造里

![](/Misc/RSA/2.png)

但RSA有个硬伤，就是慢，而且**一次只能加密很短的明文**，所以适合小数据（密码/会话密钥）

## Padding

RSA不能直接加密原文，必须先填充，通常采用`PKCS#1 v1.5`（JSEncrypt默认）

```
变换字符串：RSA/ECB/PKCS1Padding
```

> 前端用哪个填充，后端就必须用哪个。如果前端换成OAEP填充，后端会解密失败
