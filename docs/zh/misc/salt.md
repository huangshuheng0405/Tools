# Salt

哈希盐（Salt）是在哈希密码之前混入的一段随机数据，目的是让相同的密码每次哈希出来的结果都不一样，从而防止彩虹表、预计算攻击，并提高离线暴力破解的成本

> 盐不是加密，也不是密钥。盐不需要保密，通常和哈希结果一起存在数据库里

## 为什么要盐

如果直接哈希密码

- **彩虹表攻击**：攻击者可以与计算大量常见密码的哈希，直接查表反推密码
- **相同密码相同哈希**：数据库里哈希一样，破解一个等于破解一片
- **批量破解成本低**：攻击者可以一次性对海量哈希做匹配

### Java

`Hutool`工具包的`BCrypt`

加密：`BCrypt.hashpw(password, BCrypt.gensalt());`

- `password`：密码明文
- `salt`：盐

解密：`BCrypt.checkpw(rawPassword, hashedPassword); `

- `plaintext`：需要验证的明文密码
- `hashed`：密文

`checkpw`：从数据库里那串哈希里解析出盐，用同样的盐+你输入的密码重算，比对结果
