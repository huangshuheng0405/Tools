# config

配置java环境

## JDK

### Eclipse Temurin

[下载地址](https://adoptium.net/)

Spring官方推荐的JDK发行版，基于OpenJDK

JDK17或21（均为长期支持版`LTS`）

### Oracle JDK

[下载地址](https://www.oracle.com/java/technologies/downloads/#jdk27-windows)

Java技术的官方所有者，版本更新最及时，个人学习和开发免费，商业生产环境可能要付费

---

配置好之后，在命令行里验证

```bash
java -version
```

```bash
javac -version
```
