# SSH

全称**Secure Shell**，安全外壳协议。从自己电脑安全地连到远程服务器

```bash
ssh root@124.228.110.195
```

输入密码后，就能连接

- `root`：你服务器的用户名
- `@`后面是你服务器的**公网**地址

## 端口转发

把本地端口和服务器端口连起来

```bash
ssh -L 3307:127.0.0.1:3306 root@124.220.110.195
```

本地3307端口->服务器内部的3306，这样服务器就不用把3306端口暴露到公网

连接后终端不能关闭，不然连接就断了，如果想后台一直跑

- `-L`：Local Port Forwarding，本地端口转发（端口映射）
