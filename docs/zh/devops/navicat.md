# Navicat

## NySQL

针对服务器上的MySQL数据库，需要分两个**选项卡**填写

`SSH`选项卡：配置隧道入口

勾选“使用SSH隧道”（非常重要），进行填写：

| 字段     | 填写内容             | 说明                           |
| -------- | -------------------- | ------------------------------ |
| 主机     | 你的服务器**公网IP** |                                |
| 端口     | `22`                 | 服务器SSH的端口                |
| 用户名   | 你的服务器登录用户名 | 如`root`，**不是**数据库用户名 |
| 验证方式 | 密码或私钥           | 按你的服务器登录方式选择       |

`常规`选项卡：配置隧道内的数据库地址

这里已经进入到服务器内部，所以主机名不是服务器公网IP

| 字段   | 内容        | 说明                    |
| ------ | ----------- | ----------------------- |
| 连接名 | 任意        | 方便识别即可            |
| 主机名 | `127.0.0.1` | 填localhost可能失败     |
| 端口   | `3306`      |                         |
| 用户名 | 数据库用户  | 默认是`root`            |
| 密码   | 数据库密码  | 即`MYSQL_ROOT_PASSWORD` |
